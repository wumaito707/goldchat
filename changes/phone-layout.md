# GOLDCHAT phone layout

The chat experience now has a touch-first layout on phone screens.

- Full-width chat list and status rail.
- Bottom navigation for Chats, Updates, and More.
- Larger tap targets for chat items, message composer actions, and the new-chat button.
- A compact phone chat header with back, voice-call, and video-call controls.
- Safe-area-aware spacing for modern phone screens and an improved sign-in screen.

Desktop screens continue to use the existing two-column layout.
